Why ShipKit

AI agents write code fast, but they default to generic Silicon Valley SaaS. Business software in Kampala, Nairobi or Kigali needs different things, and the gaps cost real money.

Real-world needWhat agents usually doWhat ShipKit makes them do
Owner → Manager → Cashier, across branchesOne "admin" flag, no branch scopingRole enums, server-side requireRole, every query scoped by organisation and branch
MTN and Airtel mobile moneyStripe onlyMoMo request-to-pay, server-side verification, idempotent webhooks
Money that must add upFloats and client-side totalsDecimal everywhere, server totals, transactions, no hard deletes
Customers with basic phonesEmail onlySMS receipts and alerts via Africa's Talking
3G and cheap Android phonesHeavy client bundlesServer Components, offline outbox, 360px-first UI
SecurityTrusts the clientinput: false on roles, Zod everywhere, audit logs, rate limits

Get started in 3 steps

Works in a new or existing Next.js project. Safe to re-run: it never overwrites files you've edited.

1
Install the framework

Adds the master prompt, guides, planning templates and rules for your agent.

npx shipkit-africa init
2
Plan your app

Your agent asks a few questions, then writes your project description and build phases.

"Plan my app with shipkit/planning/plan-your-app.md"
3
Build phase by phase

It builds one phase, runs the checks, and stops for your review before the next.

"Build phase 1"

The framework

Plain markdown files your agent reads. init puts them in shipkit/ in your project. Edit any of them, and ShipKit won't overwrite your changes.
